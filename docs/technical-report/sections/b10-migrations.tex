\chapter{Migration history}
\label{app:migrations}

The database is defined by nine migrations in \code{supabase/migrations}. Each file is named
\code{<version>_<name>.sql}, and the migrations apply in version order. This report refers to each by its
name (\cref{tab:migrations}), listed in the order they apply. Later migrations replace earlier
definitions; the descriptions in this report always refer to the latest one.

  \code{functions} & The shared helpers (blocks, person and event cards, proximity); every public function of the first release; \code{expire_stale} and its \code{pg_cron} schedule; execution revoked from \code{public} and \code{anon} \\
  \code{storage_realtime} & The private \code{photos} bucket (5\,MiB; JPEG, PNG, WebP) with its own-folder write policies; full replica identity and the Realtime publication for \code{chat_requests} and \code{messages} \\

  \code{delete_event} & \code{delete_event}, which lets an event's host delete it; members and group-chat messages go with it by cascade \\
